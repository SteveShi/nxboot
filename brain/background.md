# Project background

NXBoot is a modern macOS application for provisioning Tegra X1 powered devices (Nintendo Switch) with early boot code in USB Recovery Mode (RCM).

## Goals
- Inject payloads (e.g. Hekate, Lakka) into Nintendo Switch devices in RCM mode.
- Pure native macOS IOKit USB stack implementation without external dependencies.
